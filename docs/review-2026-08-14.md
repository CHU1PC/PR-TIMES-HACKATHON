## 7. 問題なしと判定されたもの (再調査しないための記録)

- `docker-compose.yml` の `APP_ENV=demo` → 本番タスク定義に APP_ENV は無く既定 production。安全
- CSRF → SameSite=Lax + 変更系は全て JSON ボディ必須 + cloudfront.net は PSL 掲載。塞がっている
- OAuth state の Cookie 保持 → 標準的なステートレス実装。`compare_digest` 使用
- `retrieval/index.py` の f-string SQL → モジュール定数の float のみ。injection 不成立
- プロンプトインジェクション → self-injection のみ。コーパス経由は層別選抜のため狙って刺せない
- CORS → 明示リスト + `*` 禁止バリデータ
- `_categories` のロック無し → `place.py` と非対称だが `dict.update` は冪等なので正当
- `# ruff: ignore[...]` 構文 → **実測で行スコープに効いている**(ただし文書化された形は `# noqa:` なので寄せる)
